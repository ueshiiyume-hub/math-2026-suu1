# 次の年度への 引き継ぎ（お引っ越しの メモ）

2026-10-30 に 先生と 決めた こと。来年度（2027年度）からは、**この 公開リポジトリ（math-2026-suu1）の 名前は そのまま**に して、中を **年度 → 科目** の フォルダで 分ける。

## なぜ この 形か
- リポジトリの 名前や フォルダの 場所を 変えると、サイトの URL が 変わる。GitHub Pages は 古い URL から 転送しない ので、配った QR コード・貼った リンクが 切れる。
- 「リポジトリは 増やさない」決まりにも 合う。

## 来年度の フォルダの 形（案）
```
math-2026-suu1/            ← 名前は 変えない
├─ 2gakki-chukan/  期末考査/  _作成用/  index.html   ← 2026年度の 数学Ⅰ（動かさない）
├─ mathC/  math3/                                 ← 2026年度の 数学C・数学Ⅲ（動かさない）
└─ 2027/
   ├─ index.html          ← 2027年度の 入口（科目の カード）
   ├─ math1/              ← 数学Ⅰ（考査ごとの フォルダ、_作成用/ も この 中に）
   ├─ mathC/
   └─ math3/
```
- URL は `https://ueshiiyume-hub.github.io/math-2026-suu1/2027/math1/…` に なる。
- フォルダ名は 英数字に する（日本語だと URL が `%E6%95%B0…` の ような 長い 文字に なる）。
- いちばん上の `index.html`（2026年度の トップ）に「2027年度」の カードを 1つ 足せば、そこから 入れる。

## 2026年度の ものは どう するか
- **動かさない・消さない**（URL を 守る）。使いたい ものは **コピー** して 新しい フォルダで 使う。
- スライドや 解答の 中身を 来年も 使う ときも、コピーして 新しい フォルダで 作り直す（古い 方は そのまま 残す）。

## 引き継げる 部品（数学Ⅰ、`_作成用/`）
コピーして `2027/math1/_作成用/` に 置けば そのまま 使える もの：

| ファイル | 役目 |
|---|---|
| `engine.js`・`head.html`・`theme.html`・`core.js`・`words.js`・`extra.css` | スライドの 土台（めくる・目次・全画面・おわりの パネル・再開・明暗） |
| `ink.js`・`ink.css` | ペン（書く モード、「スライドに 戻る」ボタン） |
| `kimatsu.js`・`kimatsu.css` | 数学Ⅰ の 部品（分数・ルート・すだれ算 SUDARE・約分の 斜線 RDX・放物線 PB・probHead・ptag など） |
| `build_kimatsu.py` | スライドを 作る（デッキの 中身は decks_*.py） |
| `menus.py`・`menu.html` | 目次ページを 作る |
| `kaitou.py`・`kaitou.html`・`kaitou_no◯-◯.py` | プリントの 解答ページ（プリントの ページに 答えを 重ね、枠ごとに かくせる） |
| `versions.json` | スライドの 版と 日付（来年度は 空から 始める） |
| `skill/` | 作り方の 手順書（SKILL.md）と 撮影の 道具 |

数学C・数学Ⅲ の 部品は それぞれの `mathC/CLAUDE.md`・`math3/CLAUDE.md` を 見る（数学Ⅰ とは 部品を 共有しない 決まり）。

## コピーした あとで 直す ところ（場所が 深く なる ため）
- `build_kimatsu.py` の `PRINT_PDF`（プリントの pdf の 場所）：`os.path.join(B, '..', '..', '2026_mathc_private', …)` の `'..'` の 数と、pdf の 名前・フォルダを 新しい 年度に 合わせる。
- `kimatsu.js` の `KIMATSU`（表紙・左上に 出る「数学Ⅰ　２学期期末考査まで」）。
- `build_kimatsu.py` の `SERIES_LIST`（おわりの パネルの 並び）と デッキの 中身。
- `menus.py` の `make('期末考査/…')` の 出力先と、戻る リンク（`'../index.html'` など）。`menu.html` の「← トップへ」も。
- `kaitou.py` を 動かす コマンドの パス（CLAUDE.md の コマンド欄）。
- 新しい フォルダの `CLAUDE.md`（この ファイルの 決まりを 写して、年度・フォルダを 直す）。
- パソコンの スキル：`_作成用/skill/` を `~/.claude/skills/print-to-slides/` に コピー し直す。

## 非公開リポジトリ（2026_mathC_private）
- 名前は 変えても よい（生徒が 見る URL が ない）。変えたら `PRINT_PDF` などの パスと 各 CLAUDE.md を 直す。
- 来年度は 同じ ように `2027/数学Ⅰ/`・`2027/数学C/` … と 分ける（今年度の `数学Ⅰ/` などは そのまま）。
- 小テスト（`数学Ⅰ/小テスト/make_test.js`・`graphs.py`）や 課題テスト（`数学Ⅰ/課題テスト/`）の 作り方も コピーして 使える。
