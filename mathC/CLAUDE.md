## スライドの 作り方（①-1 で 決めた こと）
- 1つの 節 ＝ 1つの HTML。表紙 → 中身 → 問 → まとめ（まとめは アニメーション なし）
- 数式は KaTeX（jsdelivr の CDN）。`M\`z=a+bi\``（\ は そのまま 書ける）。`\RE{…}` 実部の 色、`\IM{…}` 虚部の 色、`\on{番}{re|im|dp}{…}` その番で 色が つく
- 色の 対応：**実部・実軸＝青、虚部・虚軸＝橙**、点・答え＝深い緑（全デッキ 共通）
- 複素数平面は SVG（`PL()`）。`walk(a,b,番)`＝原点から 横（青）→ 縦（橙）に 進む矢印、`dot()`＝点。次の 点に 移ったら 前の 矢印は 消す（`e:`）
- ①-2 から：`arr()`＝矢印（ベクトル）、`move()`＝矢印を 平行移動して 見せる、`flip()`＝実軸で 折り返す、`line()`＝原点を 通る 直線。和・差・実数倍・共役の ページは デッキ内の `opPage()`（例と 練習で 共通）
- ①-3 から：`seg()`＝線分（`lab` 文字、`ls` 文字が 出る 番、`side` 文字を 置く 側＝三角形の 外側に）、`ra()`＝直角の 印、`walk(…,{plain:true})`＝矢じり なしの 辺（直角三角形）。絶対値の ページは デッキ内の `absPage()`
- ①-4 から：`ang(角, 番)`＝偏角の 弧（左回り）、`PL({polar:{n, rays, labels}})`＝同心円の 目盛り、`walk(…,{below:true})`＝横の 辺の 文字を 軸の 下に。練習編（問10）は デッキ内の `prPage()` が データ（z・r・基準の 角・θ）から 1問1ページを 作る（長さ → くくる → 象限を 塗って θ → 答え）。`.pbox`＝プリントの Point の 枠
- 強調（①-4 ver 1.1 から）：`.dimo`（data-o の 番で うすくなる）、`.hl2`（出ると 淡い緑の 帯で 少し 大きく）、`.sweep`（原点から 向き θ まで 線が 回る）、`.pulse`（点の 波紋）。`ang(…,{la})` で 角の 文字の 位置を 指定
- ②-2 から：`ang(…,{from})`＝途中の 角から 回る 弧（θ₂ など）。積の 例・問は デッキ内の `mulPage()`。図の 幅は 最大 560px（横に 長い 範囲で 左の 式が 折り返さない ように）
- ②-3 から：デッキ内の `ROT()`＝原点からの 矢印が θ だけ 回る（点線の ゴースト）、回転の 例・問は `rotPage()`（回る 先を 見る → 計算 → 答えの 点）
- ③-1 から：`carc(a0, a1, 半径px, 番)`＝原点の まわりを 回る 矢印（円の 外側。点の 名前は 円の 内側に 置く）。n 乗の 例・問は デッキ内の `dmPage()`（極形式 → 長さは n 乗・向きは n 倍 → 値）
- プリントは 2026-10-23 に 更新（①-4「くくる」だけ の Point が 三角比の 表に）。プリントが 更新されたら、前の 版と 文字・空らんの 箱・図を 比べて、変わった ところを スライドに 反映する
- 部品で style を 足す ときは `at(番, 追加の style)` に まとめる（style 属性が 2つに なると 遅れ --d が 消える）
- 枠の 文が 変な ところで 折り返さない ように `<br>` を 入れる。表の マスは flex に しない（スマホで 文字が 縦に 割れる）
- 下の 説明欄（`CAP`）＝「なぜ」を 1〜2行。プリントの 空らんは `FILL(番, 答え)`（淡い緑の 箱）
- 撮影：URL の `?final#ページ-番`（例 `#4-e`＝5ページ目の 最後）で その場面から 開く。クラウドでは KaTeX を ローカルの 写しに 置きかえて 撮る（CDN に つながらない ため）
