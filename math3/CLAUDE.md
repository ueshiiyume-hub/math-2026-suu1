## スライドの 作り方（①-1〜④-4 で 決めた こと）
- 1つの プリント ＝ 1つの HTML。表紙 → 公式・方針 → 例 → 問 → まとめ（まとめは アニメーション なし）
- 数式は KaTeX。`M\`…\``＝文中、`D\`…\``＝大きい 形（\displaystyle。計算の 行・公式）
- `gridPage()`＝何問かを 格子に 並べる（短い 計算）。`c1:true` で 1列。`o:` で その 問を 光らせる 番
- `subPage()`＝置換積分の 1問 1ページ：左＝「置きかえ」の 枠（`prep`）と Point（`pt`）、右＝計算（`calc`）
- ③-1・③-2 は `ppPage()`＝部分積分の 1問（左に「選び方」：微分する方＝橙・積分する方＝紫、積、右に 計算）。④-1 は `frPage()`（割り算・部分分数）、④-4 は `pdPage()`（α・β を あてはめる）
- ①-5 は デッキ内の `adjPage()`＝当たり → 微分すると → 帳尻（プリントの 解答と 同じ 帳尻合わせ。置換積分は 使わない）
- `PT(番, 名前, 中身)`＝プリントの 解答に ある 赤枠の コメント。`FILL(番, 答え)`＝プリントの 空らん
- 下の 説明欄（`CAP`）＝その 番の「なぜ」を 1〜2行
- **終わりの パネル**（2026-10-23）：最後の ページで さらに 進むと「おわり」の パネルが 出る（次の プリントへ・もう一度 最初から・前の プリント・一覧・全デッキの リスト）。← か Esc で 最後の ページに 戻る。並びは `decks_integral.py` の DECKS の 順（`build.py` が `SERIES` として 入れる）。撮影は URL の `#end`
- **追加解説**（2026-10-26）：授業の 板書を 元に あとから 足した ページは、DECK の ページに `add:'10/26'`（足した 日）を 付ける → 見出しの 横に 橙の「追加解説 10/26」、見出しの 線も 橙、目次に「追加」。ページ名は「問2　⑶　くわしく」の ように「くわしく」を 付け、元の 問の ページの 説明欄に「次の ページで くわしく」と 書く。プリントの 解答にも 同じ 内容の 赤枠を 足す（非公開リポジトリの `add_note.py`）
- **全画面**（2026-10-26）：右下の ボタン（または F）。ブラウザの きまりで ページを 移る・読み込み直すと 全画面は 解除されるので、sessionStorage に 覚えて、次の ページで 最初に ふれた ときに 全画面に 戻す（上に「画面に ふれると 全画面に 戻ります」と 出る。その タップでは ページを 進めない）。iPhone の Safari は 全画面に できないので ボタンは 出ない
- 撮影：数学C と 同じ（`?final#ページ-番`。クラウドでは KaTeX を ローカルの 写しに 置きかえて 撮る）
