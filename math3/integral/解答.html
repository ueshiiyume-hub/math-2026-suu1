①-1x^n の不定積分↑ 目次

公式
\displaystyle\int x^{\alpha}dx=\frac{1}{\alpha+1}x^{\alpha+1}+C　（ただし \alpha\neq-1）
\displaystyle\int\frac{1}{x}dx=\log|x|+C

例　次の不定積分を求めよ。

⑴\int x^3dx
=\frac{1}{4}x^4+C
⑵\int\frac{1}{x^3}dx
=\int x^{-3}dx=-\frac{1}{2}x^{-2}+C
=-\frac{1}{2x^2}+C
⑶\int\sqrt{x}\,dx
=\int x^{\frac{1}{2}}dx=\frac{2}{3}x^{\frac{3}{2}}+C
=\frac{2}{3}x\sqrt{x}+C
⑷\int\frac{1}{x}dx
=\log|x|+C
⑸\int\frac{1}{\sqrt[3]{x^2}}dx
=\int x^{-\frac{2}{3}}dx=3x^{\frac{1}{3}}+C
=3\sqrt[3]{x}+C

問1（ノート）　次の不定積分を求めよ。

⑴\int x^5dx
=\frac{1}{6}x^6+C
⑵\int\frac{dx}{x^4}
=\int x^{-4}dx=-\frac{1}{3}x^{-3}+C
=-\frac{1}{3x^3}+C
⑶\int\sqrt[3]{x}\,dx
=\int x^{\frac{1}{3}}dx=\frac{3}{4}x^{\frac{4}{3}}+C
=\frac{3}{4}x\sqrt[3]{x}+C
⑷\int\frac{dx}{\sqrt{x}}
=\int x^{-\frac{1}{2}}dx=2x^{\frac{1}{2}}+C
=2\sqrt{x}+C

①-2x^n の不定積分　分子が多項式の場合↑ 目次

分子が多項式である場合の不定積分の方針
分子の各項を分母で割ってから，項ごとに積分する。

例　次の不定積分を求めよ。

⑴\int\frac{2x-3}{x^2}dx
=\int\left(\frac{2}{x}-\frac{3}{x^2}\right)dx
=2\log|x|+\frac{3}{x}+C

問2　次の不定積分を求めよ。

⑴\int\left(x^3+\frac{1}{x^3}\right)dx
=\int(x^3+x^{-3})dx=\frac{1}{4}x^4-\frac{1}{2}x^{-2}+C
=\frac{1}{4}x^4-\frac{1}{2x^2}+C
⑵\int\frac{2x^3+2x-4}{x^2}dx
=\int\left(2x+\frac{2}{x}-\frac{4}{x^2}\right)dx=x^2+2\log|x|+\frac{4}{x}+C
【-\frac{4}{x^2} の積分】追加 10/26
→ \displaystyle-\int4x^{-2}dx=\frac{-4}{-1}x^{-1}+C=+4x^{-1}+C
-4\div(-1)：マイナス÷マイナスでプラス
→ x^{-1}=\frac{1}{x} より +\frac{4}{x}+C
⑶\int\frac{3x-2}{\sqrt{x}}dx
=\int\left(3x^{\frac{1}{2}}-2x^{-\frac{1}{2}}\right)dx=2x^{\frac{3}{2}}-4x^{\frac{1}{2}}+C
=2x\sqrt{x}-4\sqrt{x}+C
【\sqrt{x} を指数に直す】追加 10/26
割り算は指数のひき算（\frac{x^3}{x^2}=x^{3-2}=x と同じ）
→ \displaystyle\frac{3x}{\sqrt{x}}=\frac{3x^1}{x^{\frac{1}{2}}}=3x^{1-\frac{1}{2}}=3x^{\frac{1}{2}}
→ \displaystyle\frac{2}{\sqrt{x}}=\frac{2}{x^{\frac{1}{2}}}=2x^{-\frac{1}{2}}
【分数で割る＝逆数を掛ける】追加 10/26
→ \displaystyle\frac{3}{\frac{3}{2}}x^{\frac{3}{2}}-\frac{2}{\frac{1}{2}}x^{\frac{1}{2}}+C
3\div\frac{3}{2}=3\times\frac{2}{3}=2，2\div\frac{1}{2}=2\times2=4
⑷\int\frac{(\sqrt{x}+2)^2}{x}dx
=\int\frac{x+4\sqrt{x}+4}{x}dx
=\int\left(1+\frac{4}{\sqrt{x}}+\frac{4}{x}\right)dx=x+8\sqrt{x}+4\log x+C
【\sqrt{x} があるので x>0】追加 10/26
→ \frac{\sqrt{x}}{x}=x^{\frac{1}{2}-1}=x^{-\frac{1}{2}}，4\div\frac{1}{2}=4\times2=8
→ x>0 より \log|x|=\log x

①-3三角関数の不定積分↑ 目次

公式
\displaystyle\int\sin x\,dx=-\cos x+C　　\displaystyle\int\cos x\,dx=\sin x+C　　\displaystyle\int\frac{dx}{\cos^2x}=\tan x+C

例　次の不定積分を求めよ。

⑴\int(\sin x+3\cos x)dx
=-\cos x+3\sin x+C
⑵\int\tan^2x\,dx
=\int\left(\frac{1}{\cos^2x}-1\right)dx
=\tan x-x+C
【ヒント】
1+\tan^2x=\frac{1}{\cos^2x}

問3（ノート）　次の不定積分を求めよ。

⑴\int(1-\sin x)dx
=x+\cos x+C
⑵\int\frac{\cos^3x-1}{\cos^2x}dx
=\int\left(\cos x-\frac{1}{\cos^2x}\right)dx=\sin x-\tan x+C
⑶\int(2-\tan x)\cos x\,dx
=\int(2\cos x-\sin x)dx=2\sin x+\cos x+C
【\tan x\cos x の直し方】追加 10/26
→ \tan x\cos x=\frac{\sin x}{\cos x}\times\cos x=\sin x
→ -\sin x の積分は +\cos x（符号に注意）
⑷\int\left(\tan^2x-\frac{2}{\cos^2x}\right)dx
=\int\left(-\frac{1}{\cos^2x}-1\right)dx=-\tan x-x+C
【\tan^2x の直し方】追加 10/26
1+\tan^2x=\frac{1}{\cos^2x} より \tan^2x=\frac{1}{\cos^2x}-1
→ \frac{1}{\cos^2x}-1-\frac{2}{\cos^2x}=-\frac{1}{\cos^2x}-1

①-4指数関数の不定積分↑ 目次

公式
\displaystyle\int e^x\,dx=e^x+C　　　\displaystyle\int a^x\,dx=\frac{a^x}{\log a}+C

例　次の不定積分を求めよ。

⑴\int(2e^x+1)dx
=2e^x+x+C
⑵\int3^x\,dx
=\frac{3^x}{\log3}+C

問4　次の不定積分を求めよ。

⑴\int4e^x\,dx
=4e^x+C
⑵\int5^x\,dx
=\frac{5^x}{\log5}+C
⑶\int(3x^2-2e^x)dx
=x^3-2e^x+C

①-5合成関数の不定積分↑ 目次

帳尻合わせ
まず当たりをつけて、微分して余分に出る数を打ち消す数を掛ける。
\displaystyle\int f(ax+b)\,dx=\frac{1}{a}F(ax+b)+C　（F(x) は f(x) の不定積分）

例　次の不定積分を求めよ。

⑴\int(2x+3)^4dx
=\frac{1}{2}\cdot\frac{1}{5}(2x+3)^5+C=\frac{1}{10}(2x+3)^5+C
【帳尻合わせ】
当たり：\frac{1}{5}(2x+3)^5
微分すると \times2 が余分に出る → \times\frac{1}{2}
⑵\int\sin(4x-3)\,dx
=\frac{1}{4}\cdot\{-\cos(4x-3)\}+C=-\frac{1}{4}\cos(4x-3)+C
【帳尻合わせ】
当たり：-\cos(4x-3)
微分すると \times4 が余分に出る → \times\frac{1}{4}
⑶\int\sqrt{2x+5}\,dx
=\int(2x+5)^{\frac{1}{2}}dx=\frac{1}{2}\cdot\frac{2}{3}(2x+5)^{\frac{3}{2}}+C=\frac{1}{3}(2x+5)\sqrt{2x+5}+C
【帳尻合わせ】
当たり：\frac{2}{3}(2x+5)^{\frac{3}{2}}
微分すると \times2 が余分に出る → \times\frac{1}{2}

問5　次の不定積分を求めよ。

⑴\int(3x+1)^3dx
=\frac{1}{3}\cdot\frac{1}{4}(3x+1)^4+C
=\frac{1}{12}(3x+1)^4+C
⑵\int e^{2x-3}dx
=\frac{1}{2}e^{2x-3}+C
⑶\int\sin(3x+4)\,dx
=\frac{1}{3}\cdot\{-\cos(3x+4)\}+C
=-\frac{1}{3}\cos(3x+4)+C
⑷\int\cos\left(4x-\frac{\pi}{3}\right)dx
=\frac{1}{4}\sin\left(4x-\frac{\pi}{3}\right)+C
⑸\int\sqrt{1-2x}\,dx
=\left(-\frac{1}{2}\right)\cdot\frac{2}{3}(1-2x)^{\frac{3}{2}}+C=-\frac{1}{3}(1-2x)\sqrt{1-2x}+C
⑹\int\frac{dx}{3x+5}
=\frac{1}{3}\log|3x+5|+C

②-1置換積分の不定積分↑ 目次

置換積分法
① t=（かたまり）と置く
② \frac{dx}{dt} を求め、dx=（t の式）dt として変形する
③ 式を置き換える
④ 積分し、元に戻す。

例　次の不定積分を求めよ。

⑴\int x(x-5)^4dx
x-5=t\ \text{とおくと}\ \ x=t+5
\text{両辺を}\ t\ \text{で微分すると}\ \ \frac{dx}{dt}=1\ \ \text{よって}\ \ dx=dt
=\int(t+5)t^4dt=\int(t^5+5t^4)dt
=\frac{1}{6}t^6+t^5+C=\frac{1}{6}t^6+\frac{6}{6}t^5+C
=\frac{1}{6}t^5(t+6)+C
=\frac{1}{6}(x-5)^5\{(x-5)+6\}+C=\frac{1}{6}(x+1)(x-5)^5+C
【dx の求め方】
① x を t の式で表す：x=t+5
② 両辺を t で微分：\frac{dx}{dt}=1
③ 両辺に dt をかけて：dx=dt
【分数でくくるコツ】
t^5 を \frac{6}{6}t^5 と書きかえると
→ \frac{1}{6}t^6+\frac{6}{6}t^5=\frac{1}{6}t^5(t+6)
t を x-5 に戻すときは { } の中も！
⑵\int x(2x+1)^3dx
2x+1=t\ \text{とおくと}\ \ x=\frac{t-1}{2}=\frac{1}{2}t-\frac{1}{2}
\text{両辺を}\ t\ \text{で微分すると}\ \ \frac{dx}{dt}=\frac{1}{2}\ \ \text{よって}\ \ dx=\frac{1}{2}dt
=\int\frac{t-1}{2}\cdot t^3\cdot\frac{1}{2}dt=\frac{1}{4}\int(t^4-t^3)dt
=\frac{1}{4}\left(\frac{1}{5}t^5-\frac{1}{4}t^4\right)+C=\frac{1}{20}t^5-\frac{1}{16}t^4+C
=\frac{4}{80}t^5-\frac{5}{80}t^4+C=\frac{1}{80}t^4(4t-5)+C
=\frac{1}{80}(2x+1)^4\{4(2x+1)-5\}+C
=\frac{1}{80}(8x-1)(2x+1)^4+C
【dx の求め方】
x=\frac{1}{2}t-\frac{1}{2} を t で微分すると \frac{dx}{dt}=\frac{1}{2} → dx=\frac{1}{2}dt
※ dx=dt ではないので注意！
【通分してからくくる】
20 と 16 の最小公倍数は 80 → \frac{1}{20}=\frac{4}{80}，\frac{1}{16}=\frac{5}{80}
{ } の中：4(2x+1)-5=8x-1

問6（ノート）　次の不定積分を求めよ。

⑴\int x(x-4)^3dx
x-4=t\ \text{とおくと}\ \ x=t+4
\frac{dx}{dt}=1\ \ \text{よって}\ \ dx=dt
=\int(t+4)t^3dt=\int(t^4+4t^3)dt
=\frac{1}{5}t^5+t^4+C=\frac{1}{5}t^5+\frac{5}{5}t^4+C
=\frac{1}{5}t^4(t+5)+C
=\frac{1}{5}(x-4)^4\{(x-4)+5\}+C
=\frac{1}{5}(x+1)(x-4)^4+C
【くくり方】
t^4 を \frac{5}{5}t^4 にして \frac{1}{5}t^4 でくくる
{ } の中：(x-4)+5=x+1
⑵\int(x-1)(2x+3)^4dx
2x+3=t\ \text{とおくと}\ \ x=\frac{t-3}{2}=\frac{1}{2}t-\frac{3}{2}
\frac{dx}{dt}=\frac{1}{2}\ \ \text{よって}\ \ dx=\frac{1}{2}dt
\text{また}\ \ x-1=\frac{t-3}{2}-\frac{2}{2}=\frac{t-5}{2}
=\int\frac{t-5}{2}\cdot t^4\cdot\frac{1}{2}dt=\frac{1}{4}\int(t^5-5t^4)dt
=\frac{1}{4}\left(\frac{1}{6}t^6-t^5\right)+C=\frac{1}{24}t^6-\frac{1}{4}t^5+C
=\frac{1}{24}t^6-\frac{6}{24}t^5+C=\frac{1}{24}t^5(t-6)+C
=\frac{1}{24}(2x+3)^5\{(2x+3)-6\}+C
=\frac{1}{24}(2x-3)(2x+3)^5+C
【⑵のポイント】
x-1 も t の式に直してから置き換える。
\frac{1}{4}t^5=\frac{6}{24}t^5 と分母を 24 にそろえて \frac{1}{24}t^5 でくくる。
{ } の中：(2x+3)-6=2x-3

②-2置換積分の不定積分（√ を t に）↑ 目次

例　次の不定積分を求めよ。

⑴\int x\sqrt{x-1}\,dx
\sqrt{x-1}=t\ \text{とおくと}\ \ x-1=t^2\ \ \text{より}\ \ x=t^2+1
\text{両辺を}\ t\ \text{で微分すると}\ \ \frac{dx}{dt}=2t\ \ \text{よって}\ \ dx=2t\,dt
=\int(t^2+1)\cdot t\cdot2t\,dt=\int(2t^4+2t^2)dt
=\frac{2}{5}t^5+\frac{2}{3}t^3+C
=\frac{6}{15}t^5+\frac{10}{15}t^3+C=\frac{2}{15}t^3(3t^2+5)+C
\text{ここで}\ \ t^2=x-1,\ \ t^3=t^2\cdot t=(x-1)\sqrt{x-1}
=\frac{2}{15}(x-1)\sqrt{x-1}\{3(x-1)+5\}+C
=\frac{2}{15}(3x+2)(x-1)\sqrt{x-1}+C
【√ をまるごと t とおく】
① \sqrt{x-1}=t の両辺を 2 乗して x-1=t^2
② x を t の式で表す：x=t^2+1
③ 両辺を t で微分：\frac{dx}{dt}=2t → dx=2t\,dt
※ x-1=t とおいても解けるが，\sqrt{t}（t の \frac{1}{2} 乗）の計算になる。
【分数でくくるコツ】
\frac{2}{5}=\frac{6}{15}，\frac{2}{3}=\frac{10}{15} と分母を 15 にそろえる
共通な \frac{2}{15}t^3 でくくると，( ) の中に 3t^2+5 が残る
{ } の中：3(x-1)+5=3x+2

問7　次の不定積分を求めよ。

⑴\int x\sqrt{x+1}\,dx
\sqrt{x+1}=t\ \text{とおくと}\ \ x+1=t^2\ \ \text{より}\ \ x=t^2-1
\frac{dx}{dt}=2t\ \ \text{よって}\ \ dx=2t\,dt
=\int(t^2-1)\cdot t\cdot2t\,dt=\int(2t^4-2t^2)dt
=\frac{2}{5}t^5-\frac{2}{3}t^3+C=\frac{6}{15}t^5-\frac{10}{15}t^3+C
=\frac{2}{15}t^3(3t^2-5)+C
=\frac{2}{15}(x+1)\sqrt{x+1}\{3(x+1)-5\}+C
=\frac{2}{15}(3x-2)(x+1)\sqrt{x+1}+C
【t に戻すとき】
t^2=x+1，t^3=(x+1)\sqrt{x+1}
{ } の中：3(x+1)-5=3x-2
⑵\int x\sqrt{2-x}\,dx
\sqrt{2-x}=t\ \text{とおくと}\ \ 2-x=t^2\ \ \text{より}\ \ x=2-t^2
\frac{dx}{dt}=-2t\ \ \text{よって}\ \ dx=-2t\,dt
=\int(2-t^2)\cdot t\cdot(-2t)dt=\int(2t^4-4t^2)dt
=\frac{2}{5}t^5-\frac{4}{3}t^3+C=\frac{6}{15}t^5-\frac{20}{15}t^3+C
=\frac{2}{15}t^3(3t^2-10)+C
=\frac{2}{15}(2-x)\sqrt{2-x}\{3(2-x)-10\}+C
=-\frac{2}{15}(3x+4)(2-x)\sqrt{2-x}+C
【符号に注意】
dx=-2t\,dt のマイナスを忘れない
{ } の中：3(2-x)-10=-3x-4=-(3x+4)
⑶\int x\sqrt{2x-1}\,dx
\sqrt{2x-1}=t\ \text{とおくと}\ \ 2x-1=t^2\ \ \text{より}\ \ x=\frac{1}{2}t^2+\frac{1}{2}
\frac{dx}{dt}=t\ \ \text{よって}\ \ dx=t\,dt
=\int\left(\frac{1}{2}t^2+\frac{1}{2}\right)\cdot t\cdot t\,dt=\frac{1}{2}\int(t^4+t^2)dt
=\frac{1}{10}t^5+\frac{1}{6}t^3+C=\frac{3}{30}t^5+\frac{5}{30}t^3+C
=\frac{1}{30}t^3(3t^2+5)+C
=\frac{1}{30}(2x-1)\sqrt{2x-1}\{3(2x-1)+5\}+C
=\frac{1}{30}(2x-1)\sqrt{2x-1}(6x+2)+C
=\frac{1}{15}(3x+1)(2x-1)\sqrt{2x-1}+C
【通分してからくくる】
10 と 6 の最小公倍数は 30 → \frac{1}{10}=\frac{3}{30}，\frac{1}{6}=\frac{5}{30}
6x+2=2(3x+1) の 2 で約分：\frac{1}{30}\times2=\frac{1}{15}
⑷\int\frac{x}{\sqrt{1-x}}dx
\sqrt{1-x}=t\ \text{とおくと}\ \ 1-x=t^2\ \ \text{より}\ \ x=1-t^2
\frac{dx}{dt}=-2t\ \ \text{よって}\ \ dx=-2t\,dt
=\int\frac{1-t^2}{t}\cdot(-2t)dt=\int(2t^2-2)dt
=\frac{2}{3}t^3-2t+C=\frac{2}{3}t^3-\frac{6}{3}t+C
=\frac{2}{3}t(t^2-3)+C
=\frac{2}{3}\sqrt{1-x}\{(1-x)-3\}+C
=-\frac{2}{3}(x+2)\sqrt{1-x}+C
【約分できる】
分母の t と -2t\,dt の t が約分されて消える
{ } の中：(1-x)-3=-(x+2)

②-3置換積分の不定積分（x で微分する型）↑ 目次

例　次の不定積分を求めよ。

⑴\int\sin^2x\cos x\,dx
\sin x=t\ \text{とおくと}
\text{両辺を}\ x\ \text{で微分すると}\ \ \cos x=\frac{dt}{dx}\ \ \text{よって}\ \ \cos x\,dx=dt
=\int(\sin x)^2\cdot\cos x\,dx=\int t^2dt
=\frac{1}{3}t^3+C
=\frac{1}{3}\sin^3x+C
置換のコツ
\sin x=t と置くと，\cos x\,dx=dt より \int t^2dt となることを予見しておく。
【②-1 との違い】
x=（t の式）に直しにくいときは，t=\sin x のまま両辺を x で微分する
\frac{dt}{dx}=\cos x の両辺に dx をかけて \cos x\,dx=dt
式の中の「\cos x\,dx」をまるごと dt に置きかえる
【答えの書き方】
(\sin x)^3 は \sin^3x と書く（t=\sin x を戻す）
⑵\int xe^{x^2}dx
x^2=t\ \text{とおくと}
\text{両辺を}\ x\ \text{で微分すると}\ \ 2x=\frac{dt}{dx}\ \ \text{よって}\ \ x\,dx=\frac{1}{2}dt
=\int e^{x^2}\cdot x\,dx=\int e^t\cdot\frac{1}{2}dt
=\frac{1}{2}\int e^tdt=\frac{1}{2}e^t+C
=\frac{1}{2}e^{x^2}+C
置換のコツ
x^2=t と置くと，x\,dx=\frac{1}{2}dt より \frac{1}{2}\int e^tdt となることを予見しておく。
【x\,dx をまとめて置きかえる】
2x\,dx=dt の両辺を 2 でわって x\,dx=\frac{1}{2}dt
問題の式に「x\,dx」があるので，そのまま \frac{1}{2}dt に置きかえられる

問8　次の不定積分を求めよ。

⑴\int\cos^3x\sin x\,dx
\cos x=t\ \text{とおくと}
-\sin x=\frac{dt}{dx}\ \ \text{よって}\ \ \sin x\,dx=-dt
=\int t^3\cdot(-1)dt=-\int t^3dt
=-\frac{1}{4}t^4+C
=-\frac{1}{4}\cos^4x+C
【符号に注意】
(\cos x)'=-\sin x なので
\sin x\,dx=-dt のマイナスを忘れない
⑵\int3x^2\sqrt{x^3+1}\,dx
x^3+1=t\ \text{とおくと}
3x^2=\frac{dt}{dx}\ \ \text{よって}\ \ 3x^2dx=dt
=\int\sqrt{t}\,dt=\int t^{\frac{1}{2}}dt
=\frac{2}{3}t^{\frac{3}{2}}+C=\frac{2}{3}t\sqrt{t}+C
=\frac{2}{3}(x^3+1)\sqrt{x^3+1}+C
【t の \frac{3}{2} 乗の直し方】
→ t^{\frac{3}{2}}=t\cdot t^{\frac{1}{2}}=t\sqrt{t}
⑶\int e^x(e^x+1)^2dx
e^x+1=t\ \text{とおくと}
e^x=\frac{dt}{dx}\ \ \text{よって}\ \ e^xdx=dt
=\int t^2dt
=\frac{1}{3}t^3+C
=\frac{1}{3}(e^x+1)^3+C
【展開しなくてよい】
(e^x)'=e^x なので e^xdx がまるごと dt になる
⑷\int xe^{-x^2}dx
-x^2=t\ \text{とおくと}
-2x=\frac{dt}{dx}\ \ \text{よって}\ \ x\,dx=-\frac{1}{2}dt
=\int e^t\cdot\left(-\frac{1}{2}\right)dt
=-\frac{1}{2}e^t+C
=-\frac{1}{2}e^{-x^2}+C
【例⑵と同じ形】
-2x\,dx=dt の両辺を -2 でわって
→ x\,dx=-\frac{1}{2}dt

②-4置換積分の不定積分（分子が分母の微分）↑ 目次

例　次の不定積分を求めよ。

⑴\int\frac{2x}{x^2+1}dx
x^2+1=t\ \text{とおくと}
\text{両辺を}\ x\ \text{で微分すると}\ \ 2x=\frac{dt}{dx}\ \ \text{よって}\ \ 2x\,dx=dt
=\int\frac{1}{x^2+1}\cdot2x\,dx=\int\frac{1}{t}dt
=\log|t|+C
=\log(x^2+1)+C
置換のコツ
x^2+1=t と置くと，2x\,dx=dt より \int\frac{1}{t}dt となり，\int\frac{1}{t}dt=\log|t|+C であることも先読みしておく。
【| | がはずれる理由】
x^2+1>0 なので　\log|x^2+1|=\log(x^2+1)
【公式】分子が分母の微分になっているとき
→ \displaystyle\int\frac{g'(x)}{g(x)}dx=\log|g(x)|+C
（問9 はすべてこの形）
⑵\int\tan x\,dx
\tan x=\frac{\sin x}{\cos x}\ \text{なので}\ \ \int\tan x\,dx=\int\frac{\sin x}{\cos x}dx
\cos x=t\ \text{とおくと}
\text{両辺を}\ x\ \text{で微分すると}\ \ -\sin x=\frac{dt}{dx}\ \ \text{よって}\ \ \sin x\,dx=-dt
=\int\frac{1}{\cos x}\cdot\sin x\,dx=\int\frac{1}{t}\cdot(-1)dt=-\int\frac{1}{t}dt
=-\log|t|+C
=-\log|\cos x|+C
置換のコツ
\cos x=t と置くと，\sin x\,dx=-dt より -\int\frac{1}{t}dt となる。
【\tan x はまず \frac{\sin x}{\cos x} に】
分母の \cos x を微分すると -\sin x で，分子の \sin x と符号だけちがう
だから答えにマイナスが付く

問9　次の不定積分を求めよ。

⑴\int\frac{2x-1}{x^2-x+1}dx
x^2-x+1=t\ \text{とおくと}
2x-1=\frac{dt}{dx}\ \ \text{よって}\ \ (2x-1)dx=dt
=\int\frac{1}{t}dt=\log|t|+C
=\log(x^2-x+1)+C
【| | をはずせる】
→ x^2-x+1=\left(x-\frac{1}{2}\right)^2+\frac{3}{4}>0
⑵\int\frac{x}{x^2-2}dx
x^2-2=t\ \text{とおくと}
2x=\frac{dt}{dx}\ \ \text{よって}\ \ x\,dx=\frac{1}{2}dt
=\int\frac{1}{t}\cdot\frac{1}{2}dt=\frac{1}{2}\int\frac{1}{t}dt
=\frac{1}{2}\log|t|+C
=\frac{1}{2}\log|x^2-2|+C
【| | は残す】
x^2-2 は負にもなるので，絶対値はつけたままにする
⑶\int\frac{e^x}{1+e^x}dx
1+e^x=t\ \text{とおくと}
e^x=\frac{dt}{dx}\ \ \text{よって}\ \ e^xdx=dt
=\int\frac{1}{t}dt=\log|t|+C
=\log(1+e^x)+C
【| | をはずせる】
1+e^x>0 なので絶対値はいらない
⑷\int\frac{1}{\tan x}dx
\frac{1}{\tan x}=\frac{\cos x}{\sin x}\ \text{なので}
\sin x=t\ \text{とおくと}
\cos x=\frac{dt}{dx}\ \ \text{よって}\ \ \cos x\,dx=dt
=\int\frac{\cos x}{\sin x}dx=\int\frac{1}{t}dt
=\log|t|+C
=\log|\sin x|+C
【\frac{1}{\tan x} の直し方】
1\div\frac{\sin x}{\cos x}=\frac{\cos x}{\sin x}

③-1部分積分の不定積分↑ 目次

部分積分法
\displaystyle\int f(x)g\'(x)\,dx=f(x)g(x)-\int f\'(x)g(x)\,dx
①【微分する方】f(x) の選び方：微分しやすく、微分後の式が簡単になる方を選ぶ
②【積分する方】g'(x) の選び方：積分しやすい方を選ぶ
③「微分した方」と「積分した方」の積が積分できそうかを予想しておく

例　次の不定積分を求めよ。

⑴\int x\sin x\,dx
=x(-\cos x)-\int{1\cdot(-\cos x)}dx
=-x\cos x+\int{\cos x}dx
=-x\cos x+\sin x+C
【選び方】
微分する方を x とし，積分する方を \sin x とすると，
「微分した方」と「積分した方」の積は 1\cdot(-\cos x)=-\cos x となり，積分しやすそう。
【部分積分の使い方】
f(x)=x，g'(x)=\sin x とすると
f'(x)=1，g(x)=-\cos x
→ f(x)g(x)-\int{f'(x)g(x)}dx に入れる

問10（ノート）　次の不定積分を求めよ。

⑴\int x\cos x\,dx
=x\sin x-\int{1\cdot\sin x}dx
=x\sin x+\cos x+C
【選び方】
微分する方 x，積分する方 \cos x
⑵\int x\sin3x\,dx
=x\cdot\left(-\frac{1}{3}\cos 3x\right)-\int{1\cdot\left(-\frac{1}{3}\cos 3x\right)}dx
=-\frac{1}{3}x\cos 3x+\frac{1}{3}\int{\cos 3x}dx
=-\frac{1}{3}x\cos 3x+\frac{1}{9}\sin 3x+C
【積分する方】
\sin 3x を積分すると -\frac{1}{3}\cos 3x
（①-5 の帳尻合わせ）
⑶\int(2x+1)\sin x\,dx
=(2x+1)(-\cos x)-\int{2\cdot(-\cos x)}dx
=-(2x+1)\cos x+2\int{\cos x}dx
=-(2x+1)\cos x+2\sin x+C
【微分する方】
2x+1 を微分すると 2
⑷\int(x+1)\cos2x\,dx
=(x+1)\cdot\frac{1}{2}\sin 2x-\int{1\cdot\frac{1}{2}\sin 2x}dx
=\frac{1}{2}(x+1)\sin 2x-\frac{1}{2}\cdot\left(-\frac{1}{2}\cos 2x\right)+C
=\frac{1}{2}(x+1)\sin 2x+\frac{1}{4}\cos 2x+C
【積分する方】
\cos 2x を積分すると \frac{1}{2}\sin 2x

③-2部分積分の不定積分（eˣ・log x）↑ 目次

例　次の不定積分を求めよ。

⑴\int xe^x\,dx
=xe^{x}-\int{1\cdot e^{x}}dx
=xe^{x}-e^{x}+C
=(x-1)e^{x}+C
【選び方】
微分する方を x とし，積分する方を e^x とすると，
積は 1\cdot e^x=e^x となり，積分しやすそう。
⑵\int\log x\,dx
=\int{(x)'\log x}dx
=x\log x-\int{x\cdot\frac{1}{x}}dx
=x\log x-\int{1}dx
=x\log x-x+C
【選び方】
微分する方を \log x とし，積分する方を 1 とすると，
積は \frac{1}{x}\cdot x=1 となり，積分しやすそう。
【log x は 1×log x と考える】
1=(x)' とみて，1 を積分する方にする
\log x は微分すると \frac{1}{x} になり，約分できる

問11（ノート）　次の不定積分を求めよ。

④-1分数関数の不定積分↑ 目次

方針
「分子の次数」が「分母の次数」以上の時には，分子を分母で割って，「商＋余り／分母」の形にする。
置換積分・部分積分が使えず，分母の次数が高い時には，部分分数に分解して，項ごとに積分をする。分母の次数が 1 次ならば積分可能。

例　次の不定積分を求めよ。

⑴\int\frac{2x^2+1}{x-1}dx
=\int{\left(2x+2+\frac{3}{x-1}\right)}dx
=x^{2}+2x+3\log\abs{x-1}+C
【割り算】
2x^{2}+1 を x-1 で割ると
商 2x+2，余り 3
⑵\int\frac{2}{x^2-1}dx
=\int{\frac{2}{(x-1)(x+1)}}dx=\int{\left(\frac{1}{x-1}-\frac{1}{x+1}\right)}dx
=\log\abs{x-1}-\log\abs{x+1}+C
=\log\abs{\frac{x-1}{x+1}}+C
【使える？】
置換積分 → ×（分子が分母の微分でない）　部分積分 → ×
【部分分数に分解】
→ \frac{1}{x-1}-\frac{1}{x+1}=\frac{(x+1)-(x-1)}{(x-1)(x+1)}=\frac{2}{x^{2}-1}

④-2加法定理から半角の公式・積和の公式を導く↑ 目次

導く 公式
❶ \sin^2x=\frac{1-\cos2x}{2}　❷ \cos^2x=\frac{1+\cos2x}{2}　❸ \sin x\cos x=\frac{\sin2x}{2}
❹ \sin\alpha\cos\beta=\frac{1}{2}\{\sin(\alpha+\beta)+\sin(\alpha-\beta)\}
❺ \cos\alpha\cos\beta=\frac{1}{2}\{\cos(\alpha+\beta)+\cos(\alpha-\beta)\}
❻ \sin\alpha\sin\beta=-\frac{1}{2}\{\cos(\alpha+\beta)-\cos(\alpha-\beta)\}

Ⅰ　２倍角の公式

加法定理　\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta，\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta で，\beta=\alpha とおくと
\sin2\alpha= 2\sin\alpha\cos\alpha　　\cos2\alpha= \cos^2\alpha-\sin^2\alpha
さらに \sin^2\alpha+\cos^2\alpha=1 を使うと　\cos2\alpha= 1-2\sin^2\alpha = 2\cos^2\alpha-1

Ⅱ　半角の公式・２倍角の公式の変形（２乗や積を，次数の低い式に直す）

Ⅰの式の \alpha を x にかえて，\sin^2x，\cos^2x，\sin x\cos x について解く。
\cos2x=1-2\sin^2x より　❶ \sin^2x= \frac{1-\cos2x}{2}
\cos2x=2\cos^2x-1 より　❷ \cos^2x= \frac{1+\cos2x}{2}
\sin2x=2\sin x\cos x より　❸ \sin x\cos x= \frac{\sin2x}{2}

Ⅲ　積和の公式（積を和・差に直す）

加法定理　① \sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta　② \sin(\alpha-\beta)=\sin\alpha\cos\beta-\cos\alpha\sin\beta
　　　　　③ \cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta　④ \cos(\alpha-\beta)=\cos\alpha\cos\beta+\sin\alpha\sin\beta
【①＋②】左辺どうし，右辺どうしをたす。右辺の \cos\alpha\sin\beta は打ち消し合って消える。
\sin(\alpha+\beta)+\sin(\alpha-\beta)= 2\sin\alpha\cos\beta
左辺と右辺を入れかえて，両辺を 2 でわると　\sin\alpha\cos\beta= \frac{1}{2}\{\sin(\alpha+\beta)+\sin(\alpha-\beta)\}　…❹
【③＋④】\cos(\alpha+\beta)+\cos(\alpha-\beta)= 2\cos\alpha\cos\beta　両辺を 2 でわると → ❺
【③－④】\cos(\alpha+\beta)-\cos(\alpha-\beta)= -2\sin\alpha\sin\beta　両辺を -2 でわると → ❻

④-3三角関数の不定積分（次数を下げる）↑ 目次

三角関数の不定積分
次数が高く，置換・部分積分が使えない時は，④-2 の公式❶〜❸で次数を下げて積分する
❶ \sin^2x=\frac{1-\cos2x}{2}　❷ \cos^2x=\frac{1+\cos2x}{2}　❸ \sin x\cos x=\frac{\sin2x}{2}

例　次の不定積分を求めよ。

⑴\int\sin^2x\,dx
=\int{\frac{1-\cos 2x}{2}}dx=\frac{1}{2}\int{(1-\cos 2x)}dx
=\frac{1}{2}\left(x-\frac{1}{2}\sin 2x\right)+C=\frac{1}{2}x-\frac{1}{4}\sin 2x+C
【公式❶】
\sin^{2}x=\frac{1-\cos 2x}{2} で次数を下げる
⑵\int\sin x\cos x\,dx
=\int{\frac{1}{2}\sin 2x}dx
=\frac{1}{2}\cdot\left(-\frac{1}{2}\cos 2x\right)+C=-\frac{1}{4}\cos 2x+C
【公式❸】
\sin x\cos x=\frac{\sin 2x}{2}
